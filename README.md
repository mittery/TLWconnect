# TLW Connect (ท่าลี่วิทยา คอนเนกต์)

เว็บบอร์ดและพื้นที่สื่อสารสำหรับนักเรียน ครู และบุคลากรโรงเรียนท่าลี่วิทยา พัฒนาด้วย **Node.js, Express, Socket.IO** และเชื่อมต่อฐานข้อมูลถาวรด้วย **Supabase (PostgreSQL)**

เป้าหมายของระบบคือสร้างพื้นที่แลกเปลี่ยนความคิดเห็นที่ปลอดภัย นักเรียนสามารถแสดงออกผ่านนามแฝงได้อย่างสบายใจ ขณะเดียวกันมีระบบยืนยันตัวตนหลังบ้านเพื่อป้องกันการกลั่นแกล้ง (Cyberbullying) และส่งต่อข้อมูลไปยังฝ่ายบริหารหรือครูผู้รับผิดชอบได้อย่างเป็นรูปธรรม

---

## สถาปัตยกรรมและเทคโนโลยีที่ใช้

- **Backend:** Node.js (ES Modules) + Express 4
- **Real-Time Engine:** Socket.IO 4 (ซิงค์โพสต์, คอมเมนต์, โหวต, แชตสด, แจ้งเตือนแบบทันที)
- **Database:** Supabase (Cloud PostgreSQL) + `@supabase/supabase-js` (มี In-Memory Cache ช่วยลด Latency และมีระบบ Fallback)
- **Frontend:** Vanilla HTML5, CSS3, JavaScript (ไม่ต้องผ่าน Build Tool ลดความซับซ้อนในการดูแลต่อ)
- **Audio:** Web Audio API (เสียงเอฟเฟกต์สังเคราะห์โดยไม่ต้องโหลดไฟล์เสียงภายนอก)
- **Deployment:** Render (Web Service)

## ฟังก์ชันการทำงานหลัก

### 1. ระบบตัวตนและบัญชีนักเรียน (PDPA Protected)
- นักเรียนลงทะเบียนด้วย **ชื่อ-นามสกุล**, **รหัสนักเรียน (5 หลัก)** และ **เลขบัตรประชาชน (13 หลัก)**
- **การปกป้องข้อมูลส่วนบุคคล:** ระบบไม่จัดเก็บเลขบัตรประชาชนตัวเต็มลงฐานข้อมูล แต่จะแปลงเป็น HMAC-SHA256 ควบคู่กับ Salt ลับ (`HASH_SALT`) และเก็บเพียงเลขที่ถูก Mask ไว้ (เช่น `142xxxxxxx000`)
- **การแสดงผลหน้าฟีด:** แสดงผลด้วยชื่อโค้ดเนมและอวตารแบบสุ่ม (เช่น `SilentEcho #492`) เพื่อความเป็นส่วนตัว โดยผู้ใช้สามารถสุ่มชื่อใหม่ได้
- **ระบบสิทธิ์ในโพสต์ของตนเอง:** เจ้าของกระทู้สามารถแก้ไขเนื้อหา หรือลบกระทู้ของตนเองได้

### 2. ห้องสนทนา 4 หมวดหมู่หลัก + ช่องประกาศ
1. 🌧️ **ห้องระบาย:** พื้นที่แชร์ความรู้สึก ความเหนื่อยล้า และรับกำลังใจ
2. 💡 **ห้องข้อเสนอแนะ:** นำเสนอไอเดียและแนวทางพัฒนาโรงเรียน
3. 📋 **ห้องส่งคำร้อง:** แจ้งปัญหา ซ่อมบำรุง หรือเรื่องที่ต้องการให้ฝ่ายอาคาร/ผู้ดูแลตรวจสอบ (มีระบบติดตามสถานะ: รอตรวจสอบ -> กำลังดำเนินการ -> ชี้แจงแล้ว)
4. 🧭 **ห้องแนะแนว:** ปรึกษาเรื่องการเรียน การศึกษาต่อ หรือทักษะต่าง ๆ
5. 📢 **ห้องประกาศโรงเรียน:** สำหรับฝ่ายบริหารและครูประกาศข่าวสารทางการ

### 3. ระบบยืนยันบทบาท (Role Badges)
- **นักเรียน (Student):** ยืนยันตัวตนผ่านรหัสนักเรียน
- **คุณครู (Teacher):** ยืนยันตัวตนด้วย PIN คุณครูเพื่อรับตราสัญลักษณ์ 👨‍🏫
- **สภานักเรียน (Moderator):** ยืนยันตัวตนด้วย PIN สภานักเรียนเพื่อรับตราสัญลักษณ์ 🛡️
- **ผู้ดูแลระบบ (Admin/Manager):** เข้าใช้งานผ่าน Manager Portal

### 4. การสื่อสารแบบ Real-time & แจ้งเตือน
- ฟีดกระทู้ ความคิดเห็น และยอดโหวตอัปเดตสดทันทีโดยไม่ต้องรีเฟรชหน้าเว็บ
- **Live Shoutbox:** กล่องคุยสดข้อความสั้น 140 ตัวอักษร
- **In-App & Push Notification:** แจ้งเตือนเมื่อมีประกาศสำคัญจากโรงเรียน รองรับทั้งคอมพิวเตอร์และมือถือ

### 5. ศูนย์จัดการสำหรับผู้ดูแล (Manager Portal)
เข้าใช้งานที่ `/manager.html` โดยใช้ Master Passcode:
- ตรวจสอบกระทู้ทั้งหมด พร้อมดูรหัสนักเรียนของผู้โพสต์ในกรณีที่เกิดการทำผิดกฎร้ายแรง
- ลบกระทู้/ความคิดเห็นที่ละเมิดกฎระเบียบแบบเรียลไทม์
- ตรวจสอบและจัดการรายงาน (Reports) ที่นักเรียนส่งเข้ามา
- อัปเดตสถานะและตอบกลับข้อความชี้แจงในห้องส่งคำร้อง
- ระบบระงับสิทธิ์การใช้งาน (Ban/Unban User)
- บันทึกประวัติการทำงานของผู้ดูแล (Audit Log) บันทึกลง Supabase โดยตรง
- ส่งออกข้อมูล (Export Data) เป็น JSON สำหรับทำรายงาน

## โครงสร้างตารางบน Supabase

ระบบใช้งานตาราง PostgreSQL ทั้งหมด 7 ตารางพร้อมเปิดใช้งาน Row Level Security (RLS):

| ตาราง | รายละเอียดข้อมูล |
|---|---|
| `users` | ข้อมูลบัญชีนักเรียน, รหัส Hash, Token, เวลาเข้าสู่ระบบล่าสุด |
| `posts` | กระทู้, หมวดหมู่ห้อง, แท็ก, คะแนนโหวต, รีแอ็กชัน, สถานะคำร้อง |
| `comments` | ความคิดเห็นในแต่ละกระทู้ ผูกกับ `post_id` (Cascade Delete) |
| `reports` | ข้อมูลการรายงานกระทู้ไม่เหมาะสมและสถานะการตรวจสอบ |
| `banned_users` | รายชื่อนักเรียนหรือตัวตนที่ถูกระงับสิทธิ์ |
| `shouts` | ประวัติข้อความในกล่องคุยสด Live Shoutbox |
| `audit_logs` | ประวัติการกระทำของผู้ดูแลระบบ |

## การติดตั้งและรันในเครื่อง (Local Development)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. ตั้งค่า Environment Variables
คัดลอกไฟล์ `.env.example` เป็น `.env`:
```bash
cp .env.example .env
```
เปิดไฟล์ `.env` แล้วใส่ค่าจริงจาก Supabase Dashboard (**Project Settings -> API**):
```env
PORT=3000
NODE_ENV=development

ADMIN_PASSCODE=tlw2026
TEACHER_PIN=tlw-teacher-2026
MOD_PIN=tlw-mod-2026
HASH_SALT=tlw_connect_secret_salt_2026

SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_secret_key
```

### 3. เริ่มต้นรันเซิร์ฟเวอร์
รันแบบปกติ:
```bash
npm start
```
หรือรันแบบ Watch mode (รีโหลดอัตโนมัติเมื่อแก้โค้ด):
```bash
npm run dev
```

เปิดเบราว์เซอร์ไปที่:
- **หน้าเว็บหลัก:** `http://localhost:3000`
- **หน้า Manager Portal:** `http://localhost:3000/manager.html`

## การ Deploy ขึ้น Render

1. Push โค้ดขึ้น Git Repository (GitHub)
2. สร้าง Web Service บน Render (หรือตั้งค่าผ่าน `render.yaml`)
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
3. ไปที่แท็บ **Environment** ใน Render Dashboard และเพิ่มตัวแปรให้ครบถ้วน:
   - `NODE_ENV` = `production`
   - `ADMIN_PASSCODE` = *(ตั้งรหัสผ่านสำหรับ Manager Portal ความยาว 16 ตัวอักษรขึ้นไป)*
   - `TEACHER_PIN` = *(ตั้งรหัส PIN สำหรับคุณครู)*
   - `MOD_PIN` = *(ตั้งรหัส PIN สำหรับสภานักเรียน)*
   - `HASH_SALT` = *(สตริงสุ่มความยาว 32+ ตัวอักษร สำหรับใช้แฮชเลขบัตร ปชช. ห้ามเปลี่ยนหลังจากมีผู้ใช้สมัครแล้ว)*
   - `CLIENT_ORIGIN` = `https://your-domain.onrender.com`
   - `SUPABASE_URL` = *(Project URL จาก Supabase)*
   - `SUPABASE_SERVICE_ROLE_KEY` = *(service_role secret key จาก Supabase)*
