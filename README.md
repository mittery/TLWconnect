# 🤝 TLWconnect — Real-Time Anonymous Forum

เว็บบอร์ดนิรนามแบบ Real-time ดีไซน์ล้ำสมัย (Cyber-Glassmorphism) ทำงานด้วย **Node.js + Express + Socket.io** พร้อมระบบเสียงสังเคราะห์ Web Audio API และความปลอดภัยระดับ Zero-Log Anonymous 100%

---

## 📁 ห้องสนทนาหลัก 4 ห้อง
1. 🌧️ **ห้องระบาย** — พื้นที่ระบายความรู้สึก ปลดปล่อยความในใจ ความเหนื่อยล้า และรับกำลังใจ
2. 💡 **ห้องข้อเสนอแนะ** — แชร์ไอเดียสร้างสรรค์ เสนอแนะแนวทางพัฒนาพื้นที่หรือระบบ
3. 📋 **ห้องส่งคำร้อง** — ส่งคำร้องเรียน แจ้งซ่อมบำรุง หรือเรื่องที่ต้องการให้ผู้ดูแลตรวจสอบ
4. 🧭 **ห้องแนะแนว** — ปรึกษาแนวทางการเรียนรู้ ทักษะ การพัฒนาตนเอง และคำแนะนำจากผู้มีประสบการณ์

---

## ✨ ไฮไลท์ฟีเจอร์

1. **🎭 ตัวตนนินามอัตโนมัติ (Zero Registration / 100% Privacy)**
   - ไม่ต้องสมัครสมาชิก ไม่เก็บอีเมล ไม่เก็บ IP หรือข้อมูลส่วนตัว
   - สุ่มชื่อโค้ดเนม, อวตารไอคอน และสีประจำตัว (เช่น `PhantomEcho #402`, `CreativeThinker #991`)
   - สามารถกดลูกเต๋า 🎲 เพื่อสุ่มชื่อใหม่ หรือปรับแต่งอวตารได้ตลอดเวลา

2. **⚡ Real-Time Socket.io Synchronization**
   - เมื่อมีใครเปิดกระทู้ใหม่ โพสต์จะเด้งขึ้นหน้าฟีดของทุกคนทันทีแบบเรียลไทม์พร้อมการแจ้งเตือน
   - ระบบ Upvote / Downvote ปรับคะแนนสดทันที
   - แถบแสดงจำนวนคนออนไลน์สด (🟢 Online Users Badge)

3. **💬 ระบบความเห็นแบบสด & Typing Indicator**
   - กดดูคอมเมนต์ในแต่ละกระทู้ได้แบบพับเก็บ/เปิดออก
   - มีระบบแสดงสถานะว่า "กำลังพิมพ์ตอบกลับ..." แบบสดๆ ให้ผู้ร่วมสนทนาเห็น

4. **💥 ปฏิกิริยาอีโมจิ & เอฟเฟกต์ลอย (Floating Reactions)**
   - ส่งอีโมจิ reaction (🔥, 💀, 💡, 🤫, ❤️)
   - แอนิเมชันอีโมจิลอยละล่องบนหน้าจอตามพิกัดที่คลิก

5. **📢 Live Shoutbox (ห้องคุยสดสั้นๆ ทางขวา)**
   - กล่องข้อความสั้น 140 ตัวอักษรสำหรับทักทาย ระบาย หรือแลกเปลี่ยนความคิดอย่างรวดเร็ว

6. **📁 ห้องสนทนาหลัก 4 ห้อง (Channels)**
   - `🌧️ ห้องระบาย`
   - `💡 ห้องข้อเสนอแนะ`
   - `📋 ห้องส่งคำร้อง`
   - `🧭 ห้องแนะแนว`

7. **🔊 ระบบเสียงประกอบ Web Audio API**
   - มีเสียงสังเคราะห์ snappy (เสียงคลิก, เสียงโหวต, เสียงป๊อปอีโมจิ, เสียงส่งโพสต์) ไม่ต้องโหลดไฟล์เสียงภายนอก
   - มีปุ่มเปิด/ปิดเสียง (Mute Toggle) จดจำการตั้งค่าไว้ในเครื่อง

8. **💾 ข้อมูลคงอยู่ (Data Persistence)**
   - บันทึกกระทู้และ shoutbox อัตโนมัติลงใน `data/posts.json` และ `data/shouts.json` ทำให้ข้อมูลไม่หายเวลารีสตาร์ทเซิร์ฟเวอร์

9. **🛡️ ศูนย์จัดการสำหรับผู้ดูแล (Manager Portal / Moderation Center)**
   - แยกหน้าเฉพาะสำหรับการควบคุมและตรวจสอบการละเมิดกฎ: 👉 **http://localhost:3000/manager.html**
   - มีระบบป้องกันความปลอดภัยด้วย **Master Passcode** (ค่าเริ่มต้น: `tlw2026`)
   - **ลบกระทู้ละเมิดกฎแบบ Real-time** (เลือกเหตุผลได้ เช่น คำหยาบ, คุกคาม, สแปม) โดยกระทู้จะหายไปจากหน้าจอผู้ใช้ทุกคนทันที
   - **ระบบแบนผู้ใช้ (Ban User)**: สั่งแบนชื่อ Anon ผู้กระทำผิดไม่ให้สร้างกระทู้ คอมเมนต์ หรือส่งข้อความ shoutbox ได้อีก
   - **ตรวจสอบและลบคอมเมนต์**: เปิดดูคอมเมนต์ในแต่ละกระทู้และสั่งลบได้
   - **Audit Log**: มีระบบบันทึกประวัติทุกการดำเนินการของผู้ดูแลเก็บไว้ใน `data/audit_logs.json`
